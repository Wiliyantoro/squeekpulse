How the score works

Integrity Index = 100 − penalty, where penalty = lag% × 4 (capped 60) + freshness penalty (0/25/60) + incident penalty (50) + oracle rejection (30). Purely computed client-side from public API values — transparent, reproducible, and biased to warn rather than reassure.
Not affiliated with Squeekchain. Built as a Genesis Buildooooor project. All numbers parsed as BigInt; API responses are treated as untrusted input; nothing is written to any chain.
